## 新学的概念

- **for 循环 + range**：`range(起点, 终点, 步长)`，终点不含；`range(1, 101)` 就是 1~100。
- **累加器 / 累乘器套路**：盒子初始值——加法从 0 开始（加 0 不变），乘法从 1 开始（乘 1 不变）。
- **print 逗号版 vs f-string**：逗号版把多个东西并列交给 print（自动加空格）；f-string 把变量嵌进一句话中间（格式完全由你控制）。
- **复杂度在什么情况下才有意义**：只有当程序里有「会随输入变化的 n」时。写死 100 的程序，两者都是常数工作量。
- **降低变化率 vs 降低值**：大 O（变化率）是第一刀，决定 n 很大时谁赢；同变化率时再比常数。
- **公式 vs 循环**：数据是「生成的」（等差等有规律）才可能有公式 O(1)；数据是「给定的」（数组）必须逐个看，O(n) 是下限。
- **优化优先级**：正确性（先跑对）→ 可读性（让人看懂）→ 性能（必要时才优化）。

## 挑战题精华：判断质数的 √n 优化

- 只要 n 有因数，就必然有一个因数 ≤ √n（因为若 a、b 都比 √n 大，则 a×b > n）。
- 所以从 2 试到 √n 都没整除，n 就是质数。
- 判断一个数：试到 n-1 是 O(n)，试到 n//2 是 O(n/2)，试到 √n 是 **O(√n)**。
- 打印 2~N 的所有质数（每个都试到 √num）≈ **O(N√N)**。
- 跳过偶数：永远安全的优化（2 单独处理，其余只遍历奇数）。
- 写死「只查 3、5、7」：只在范围 < 11² = 121 时正确（121 = 11×11 会漏网）。
- 大范围的正解是**筛法**（O(N log log N)），以后学。
