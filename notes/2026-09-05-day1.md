## 新学的概念

- **变量**：贴了标签的盒子；**f-string**（`f"..."` + `{变量}`）把变量填进字符串。
- **while True + break**：不知道循环几次、退出条件在循环中间才出现时的万能套路。
- **try / except**：异常处理，不是 if！`except` 要写具体类型（如 `ValueError`），裸 `except` 会把真正的 bug 藏起来。
- **continue**：这次不算，回到循环开头重新来。
- **时间复杂度入门**：没有循环 = O(1)；一层循环 = O(n)；两层嵌套 = O(n²)；每次砍一半 = O(log n)。
- **读代码 vs 写代码**：读 = 辨认，写 = 设计。先写中文步骤（伪代码）再翻译成代码；套路 + 骨架 + 小步迭代。
- **PyCharm**：右上角运行键绑定「运行配置」，新文件第一次要 右键 → Run，或 Ctrl+Shift+F10，或在 Terminal 里 `python 文件名.py`。
