## 新学的概念

- **列表 list**：`[ ]` 装一串东西；下标从 0 开始；`[-1]` 取倒数第 1 个；`len()` 长度；`append()` 末尾添加。
- **遍历两种写法**：`for x in 列表` 拿元素；`for i in range(len(列表))` 拿下标（再 `列表[i]`）。
- **split()**：把字符串按分隔符切开，`"12 34".split()` → `["12", "34"]`（默认按空格）。
- **input() 的本质**：它会卡住等你按回车，但**不校验内容**；「是不是数字」由 `int()` 抛 `ValueError` 把关。
- **函数返回值要「接住」**：`int(number)` 单独写 = 取款机吐了钱但你没拿；要 `number = int(number)` 或用 `int(number)` 直接作为参数。`int()` 不修改原变量，它返回一个**新值**。
- **循环的本质**：程序是顺序执行的，循环是所有语言共通的「重复机制」；`for` = 知道次数，`while` = 靠条件停。
- **失败重试要从干净状态开始**：容器若建在循环外，失败尝试的半成品会残留并污染下一次 → 把初始化放进循环里，每轮清空。
- **异常不会「回滚」已做的修改**：单个 `append` 要么执行要么不执行（原子）；但一整轮循环不是「全成或全不成」——前面的成功不会因后面的报错被撤销。
- **变量名别占用内置名**：`list`、`sum`、`max` 都是 Python 自带的名字，用作变量会埋坑。
