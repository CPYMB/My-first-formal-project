## 新学的概念

- **函数 = 打包动作**：`def 名(参数): ... return 结果`；参数是输入，return 是输出。
- **没有 return 的函数返回 None**；`print` 给人看，`return` 给程序用。
- **返回值要接住**：`max_of_two(7,3)` 单独写结果会丢，要 `x = max_of_two(7,3)`。
- **return False 可以在循环里提前走**（找到一个反例就够）；**return True 必须等循环全部跑完**（"都是质数"要证明所有数都除不尽）。
- **import 一个 .py 会把它整个执行一遍**——这是今天"运行到旧文件"的元凶；复用代码应把函数放进模块再 import。
- **单一职责（今天的顿悟）**：函数只做一件事、接收"干净"的输入；解析/转换等"脏活"放在函数外面。
- **分层写法**：底层纯函数（如 `max_of_list`）+ 上层包装函数（负责把用户输入解析好再调用底层）——数据来源变了只改上层。
- **变量作用域**：函数里的变量是"函数自己的盒子"，外面看不到。
