# My First Formal Project · 我的学习记录仓库

> 一个计算机专业大学生的自学记录仓库：以《数据结构与算法》为主线，
> 同步把 Python 从零捡起来，并用 GitHub 记录、展示整个学习过程。

## 这个仓库是做什么的

把「学过的知识」变成看得见的东西：笔记、亲手写的代码、刷题记录、项目研读报告。
目标不是「看起来很努力」，而是**每天留下一点点可验证的进步**。

## 学习主线

1. **数据结构与算法**（本学期课程主线）
   - 学校课程用 C/C++ 讲；本仓库用 Python 动手实现，概念通用，我会做 C ↔ Python 对照。
2. **Python**：从零捡起（摸底确认：目前只会 print，所以从地基开始）。
3. **计算机基础**：复杂度思维、数据在内存里怎么存、程序如何运行。
4. **GitHub 与开源素养**：会读优秀开源项目（操作暂时由我代劳，逐步教你）。

## 学习习惯（铁律）

- 每天学一点：写代码或看网课记 2–3 句 → 发给我 → 我存档并上传。
- 代码必须亲手敲（在聊天里写也算）；复制粘贴后「假装会了」= 没学。
- 遇到问题：先自己想 → 发我一起拆；不会就直说「不会」。
- 每周日做一次复盘，更新进度表。
