# My First Formal Project · 我的学习记录仓库

> 一个计算机专业大学生的自学记录仓库：以《数据结构与算法》为主线，
> 同步提升 Python 水平与计算机基础，并用 GitHub 记录、展示整个学习过程。

## 这个仓库是做什么的

把「学过的知识」变成看得见的东西：笔记、亲手写的代码、刷题记录、项目研读报告。
目标不是「看起来很努力」，而是**每天留下一点点可验证的进步**。

## 学习主线

1. **数据结构与算法**（本学期课程主线，用 Python 动手实现）
2. **Python**：从「会语法」到「会写程序」
3. **计算机基础**：内存、进制、程序如何运行、复杂度思维
4. **GitHub 与开源素养**：会 clone、会协作、会读优秀开源项目

## 学习习惯（铁律）

- 每天学完：写笔记或刷题 → `git commit` → `git push`，让 GitHub 留下学习轨迹。
- 代码必须亲手敲；复制粘贴后「假装会了」= 没学。
- 遇到 bug：先自己读错误信息 → 拆解定位 → 实在不行再求助，并把坑记进笔记。
- 每周日做一次复盘，更新进度表。
