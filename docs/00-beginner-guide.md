# 新手须知：先看懂你的学习仓库

> 这一页用大白话解释你眼前这些东西是什么。不用背，遇到再看。

## 1. 仓库 = 文件夹 + 时光机 + 云端展示柜

- **文件夹**：就是你电脑里 `E:\py alpha project` 这个文件夹。
- **Git（时光机）**：一种记录工具。每次「存档」时记下当时所有文件的样子，以后可以随时回到过去的任何一版。
- **GitHub（云端展示柜）**：把存档传到网上，用来展示学习过程，也防止电脑坏了丢东西。
- 现阶段「存档 + 上传」都由我帮你操作，你只负责学习和写内容。

## 2. 文件类型：名字后面那个小尾巴

每个文件名最后都有一段小尾巴，叫**扩展名**，表示它是哪种文件：

| 扩展名 | 它是什么 | 怎么打开 |
| --- | --- | --- |
| `.md` | Markdown：一种「带简单格式的纯文本」，GitHub 会自动把它排版成好看的页面（标题、表格、链接） | 记事本、PyCharm 都能打开 |
| `.py` | Python 程序文件，电脑可以用 Python 运行它 | 用 PyCharm 打开并运行 |
| `.gitignore` | Git 的「黑名单」，告诉 Git 哪些文件不要上传（比如 PyCharm 的临时配置） | 文本文件，一般不用动 |

> 现在不用记住全部。之后每天用到哪个文件，我会当场用大白话讲给你听。

## 3. 仓库里各文件是干嘛的（一句话版）

| 文件 / 文件夹 | 一句话 |
| --- | --- |
| `README.md` | 仓库主页、门面：写目标和进度 |
| `docs/` | 放「学习计划」和「说明书」，比如本页 |
| `notes/` | 你的学习笔记 |
| `code/` | 你亲手写的 Python 代码 |
| `leetcode/` | 刷题记录 |

## 4. 我们每天怎么配合

1. 我发给你「今日任务」，每天 1 个，很小。
2. 你在聊天里把该写的写出来发我（代码、答案、大白话都行）。
3. 我检查、运行、帮你把内容整理存进仓库，再上传到 GitHub。
4. 你暂时不用碰 Git；等你熟练一些，我再一步步教你亲手操作。
