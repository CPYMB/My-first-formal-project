## 1. 三个重要决定（先想清楚，后面不纠结）

1. **用 Python 练手，但概念对齐你的 C 课。**
   你的课用 C/C++，这里为什么用 Python？
   - 这个仓库本来就是 Python 项目，你想提升 Python 水平；
   - Python 写起来快，能把精力放在「数据结构与算法的思想」上，而不是和编译报错搏斗；
   - 思想是通用的：C 的数组/指针/结构体 ↔ Python 的 list/引用/类，一一对应。
   学每个概念时，我会顺带给你做 C ↔ Python 的对照。概念扎实后，如果你想，我们再开 C 版练习帮课程考试。

2. **每个任务都 ≤ 30 分钟。** 学不完就留到明天，绝不让「今天没完成」打击信心。

3. **碎片时间看网课 = 正式学习的一部分。** 我给你「带着问题看」的方法，看完用两三句话记下来，
   回来讲给我听，我帮你整理成仓库里的笔记。这样没电脑的时间也在进步。

## 2. 三周总目标（学完你应该能）

1. 独立写 30–50 行的 Python 小程序（变量、判断、循环、列表、函数）。
2. 用代码实现并**讲给别人听**：数组和链表区别、栈（后进先出）、队列（先进先出）。
3. 理解「大 O 复杂度」：能说出冒泡排序 O(n²)、二分查找 O(log n)、字典查找平均 O(1)。
4. 会写：冒泡/选择排序、二分查找、递归（阶乘、斐波那契）。
5. 理解二叉树和三种遍历；知道为什么 dict 查找这么快。
6. 完成第一次「读开源项目」，产出解剖报告存进仓库。
7. （可选）LeetCode 简单题热身 3–5 道。
8. 养成双轨习惯：碎片时间看网课 + 整块时间动手写，每周复盘一次。

## 4. 每周计划

### 第 1 周（09-07 ~ 09-13）：Python 地基

目标：从只会 print 到能写 30 行小工具。**一个单元可能花 1–2 天，按你的速度来，不赶。**

知识单元（每单元配 1 个小练习，练习由我每天在聊天里给你）：
- [ ] U1 程序与 print；变量 = 贴标签的盒子；文字要加引号、数字不用
- [ ] U2 输入 input；数字与文字（int / str）
- [ ] U3 判断 if / elif / else；比较运算符
- [ ] U4 for 循环 + range（让电脑数数）
- [ ] U5 while 循环（知道 break 大概是什么即可）
- [ ] U6 列表 list：一组数据；len / max / min；遍历；append
- [ ] U7 函数 def：参数、返回值（把动作打包，以后数据结构都靠它）

穿插概念（配合你的网课，先混个脸熟）：
- [ ] 算法是什么、为什么要学数据结构
- [ ] 复杂度直觉：O(1) 秒回 / O(n) 逐个看 / O(n²) 双重循环

练习清单（由易到难，5 个左右）：
- [ ] ① 用变量存名字年龄，打印「我叫 XX，今年 XX 岁」
- [ ] ② 温度转换器（摄氏 ↔ 华氏）
- [ ] ③ 用 for 算 1+2+…+n
- [ ] ④ 在一串数字里找最大
- [ ] ⑤ 简易计算器（用函数）

本周输出（验收）：
- [ ] 每晚把练习代码或问题发我（聊天里发就行）
- [ ] 笔记 ≥ 2 篇（用 notes/ 模板，内容我帮你整理也行）
- [ ] 练习代码我帮你存进 code/ 并上传

### 第 2 周（09-14 ~ 09-20）：字典 + 线性表（数组 / 链表 / 栈 / 队列）

目标：接触第一批「数据结构」，并第一次感受到「算法快慢」的差别。

知识单元：
- [ ] U1 字典 dict：键值对、遍历、计数（为哈希表埋伏笔）
- [ ] U2 列表进阶：切片、排序、嵌套列表；常用字符串方法
- [ ] U3 复杂度入门：怎么数循环嵌套 → 大 O 直觉（配网课）
- [ ] U4 数据结构与 ADT 概念；数组 vs 链表（配网课 + 我给你画图对照）
- [ ] U5 栈：后进先出；用 list 模拟 push/pop；例子：撤销、浏览器后退
- [ ] U6 队列：先进先出；例子：排队打饭、打印机任务

练习清单：
- [ ] ① 统计一句话里每个字/字母出现次数（用 dict 计数）
- [ ] ② 括号匹配检查器：输入 `({[]})` 判断合不合法
- [ ] ③ 「最近浏览记录」：用栈模拟后退
- [ ] ④ 冒泡排序，并在代码里数一数比较了多少次

本周输出（验收）：

## 5. 碎片时间看网课：怎么才算「看进去了」

别光「看」。每看完一集，问自己三个问题，并**用手机备忘录记 2–3 句话**：

1. 这一集讲的**东西**是什么？它解决什么问题？
2. 它**快不快**（复杂度）？为什么？
3. 生活/代码里**哪里见过**它？

记下来的东西，回来在聊天里讲给我听（大白话就行），我帮你整理成仓库笔记。
哪怕只回答出问题 1，也比「刷完一集」强十倍。

- 从 `print("你好，数据结构")` 起步完全没问题，你已经会第 1 题了。
