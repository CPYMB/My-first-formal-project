## 1. 三周总目标（学完你应该能）

1. 不查资料，手写：单链表、栈、队列、二分查找、冒泡/选择/插入/归并/快排、二叉树遍历、二叉搜索树的插入与查找。
2. 对任何一段代码，能说出大致的**时间复杂度**（O(1) / O(n) / O(log n) / O(n log n) / O(n²)）并解释原因。
3. 说清 Python 里 `list`、`dict`、`set` 的底层大概是什么，各自擅长什么操作。
4. 用「类」把一种数据结构封装成抽象数据类型（ADT），并给它写测试。
5. LeetCode 累计独立完成 **20–30 道简单题**（含 2–3 道中等），每道能讲思路。
6. 独立完成一次 **GitHub 优秀项目「解剖」**，产出报告，存进本仓库。
7. 熟练日常 Git：`clone / add / commit / push / pull / branch / log`。
8. 养成习惯：每天有输出、每周有复盘，仓库 README 进度真实可查。

## 3. 贯穿三周的「计算机素养」小课堂

每周挑 1–2 个话题，花 10 分钟阅读，再用自己的话写一小段放进当周笔记：

- **W1**：数据在内存里怎么存——进制、字节、变量名 vs 地址、引用是什么。

- **W3**：从「写脚本」到「写工程」——模块、包、测试、README 的作用。

## 4. 第 1 周（09-07 ~ 09-13）：Python 进阶 + 复杂度 + 数组 / 链表

### 4.1 本周目标
把 Python 从「认得语法」提升到「能写有结构的程序」，同时建立**复杂度思维**，亲手实现第一个数据结构：链表。

### 4.2 要掌握的概念（按天拆，每天一小块）

**Python 查漏补缺（用写程序来复习，别再从头看语法书）**
- [ ] 可变 vs 不可变对象；`a = b` 到底是复制还是共享；深浅拷贝
- [ ] 列表/字典/集合的常用操作，以及它们各自大概多快（为复杂度做铺垫）
- [ ] 切片、推导式、`enumerate`、解包等「Pythonic」写法
- [ ] 函数进阶：默认参数、`*args / **kwargs`、作用域、`lambda`
- [ ] 类与对象：`__init__`、`__str__`/`__repr__`、属性和方法；为什么数据结构要用类封装（引出 ADT：抽象数据类型）

**复杂度分析**
- [ ] 大 O 记号的含义（只关心增长趋势，不看常数）
- [ ] 认识常见复杂度：O(1) < O(log n) < O(n) < O(n log n) < O(n²)
- [ ] 会数循环的嵌套层数；知道递归的复杂度要画递归树

**线性结构**
- [ ] Python 的 `list` 底层是**动态数组**：按下标访问 O(1)、中间插入/删除 O(n)
- [ ] 理解「链表」为什么存在：插入删除快、不连续内存，但按下标访问慢
- [ ] 数组 vs 链表的对比表（写进笔记）

### 4.3 动手任务

## 5. 第 2 周（09-14 ~ 09-20）：栈、队列、递归、排序、二分查找

### 5.1 本周目标
掌握「受限的线性表」——栈和队列；把递归学扎实（它是后面树和图的地基）；亲手实现并对比主流排序。

### 5.2 要掌握的概念

**栈 Stack（后进先出）**
- [ ] 用数组和链表两种方式实现；理解两种实现的取舍
- [ ] 现实映射：函数调用栈、浏览器后退、编辑器撤销
- [ ] 经典应用：括号匹配、表达式求值（中缀转后缀可以只了解）

**队列 Queue（先进先出）**
- [ ] 数组实现队列的「假溢出」问题 → 循环队列
- [ ] Python 的 `collections.deque` 双端队列
- [ ] 优先队列概念（堆，第 3 周再深入）

**递归**
- [ ] 递归三要素：终止条件、递归调用、问题规模递减
- [ ] 画递归树理解执行过程；斐波那契的重复计算 → 记忆化（memoization）
- [ ] 汉诺塔：亲手写，别背代码
- [ ] 递归 vs 迭代：什么时候能互相转换

**排序（本周重头戏）**
- [ ] 冒泡 / 选择 / 插入：实现 + 说出复杂度 + 什么数据下表现好
- [ ] 归并排序：分治思想，联系递归，O(n log n)
- [ ] 快速排序：分区思想、为什么最坏 O(n²)、随机化枢轴
- [ ] 稳定性是什么意思，哪些排序稳定

**二分查找**
- [ ] 在有序数组里找目标：模板 + 边界条件（`left <= right` vs `left < right`）
- [ ] 能说出为什么必须有序、每次砍一半 → O(log n)

### 5.3 动手任务
