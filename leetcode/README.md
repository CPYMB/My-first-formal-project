## 约定

- 题解代码放在 `leetcode/题号-题名.py`，例如 `leetcode/0001-two-sum.py`。
- 每个文件开头写注释：题目链接、思路、复杂度、踩过的坑。
- 做完一道题就在记录表加一行；每周末按「数据结构/算法」把本周题目分类统计一次。
- AC 不了很正常：自己思考 20–30 分钟没思路，就去看官方题解或讨论区，看懂后**关掉题解自己重写一遍**。
- 写代码前先在草稿纸上想清楚：输入是什么、输出是什么、用什么数据结构、大概几重循环。
